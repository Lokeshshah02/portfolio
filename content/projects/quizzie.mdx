# Quizzie Application

The Quizzie application is designed to create an engaging and seamless experience for creating and managing quizzes and polls.

## Overview
Built with TypeScript and React.js, this application emphasizes strong typings and predictable state management.

## Key Features
- **User Authentication:** Secure login and registration.
- **Analytics:** Dedicated analytics pages displaying total questions, options, and impression counts per quiz and poll.
- **Link Sharing:** Generate public links for quizzes to be shared effortlessly.

## Architecture & Learnings
I utilized REST APIs to handle backend communication, ensuring responsive UI elements reflect real-time data states correctly.
