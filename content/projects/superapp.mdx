# Super App

A versatile personal dashboard acting as a one-stop hub for your daily information needs.

## Overview
Designed to consolidate multiple daily tasks, the Super App integrates various external APIs into a unified dashboard interface behind a secure login/signup flow.

## Key Features
- **Movie Selection:** Genre-based filtering and browsing.
- **News Feed:** Real-time updates from global news sources.
- **Utilities:** Live weather reports, a stopwatch, and a persistent notepad.

## Challenges Solved
Managing state across so many disparate features was complex. I leveraged React's context and hooks to ensure the data flow remained manageable and performant, utilizing SCSS for modular styling.
